# LAB01: เรื่อง ระบบทางเทคโนโลยี (Technological System)

ใบงานแบบ Interactive สำหรับรายวิชา **ออกแบบและวิทยาการคำนวณ 2** ชั้นมัธยมศึกษาปีที่ 1 จัดทำขึ้นในรูปแบบ HTML + CSS + JavaScript ที่จำลองหน้ากระดาษ A4 มาตรฐาน พร้อมระบบตรวจคำตอบ บันทึกฉบับร่างอัตโนมัติ และฟังก์ชัน Export เป็นไฟล์ PDF

🔗 **Repository:** [https://github.com/Peelaphat2544/LAB01_Technological_System.git](https://github.com/Peelaphat2544/LAB01_Technological_System.git)

---

## 📋 คุณสมบัติเด่น (Features)

1. **โครงร่างขนาดมาตรฐาน A4 (210mm × 297mm)**
   - จัดหน้ากระดาษในสัดส่วน A4 แท้ทั้ง 3 หน้า (และหน้า 4 สำหรับแผ่นเฉลยครูผู้สอน)
   - ขนาดตัวอักษรใหญ่ ชัดเจน อ่านง่าย สบายตา
   - รองรับทั้งการทำบนหน้าจอ และการสั่งพิมพ์ผ่านเครื่องพิมพ์โดยไม่ล้นหน้ากระดาษ

2. **ระบบการตอบคำถามแบบ Interactive**
   - ตัวเลือกระบบทางเทคโนโลยี 4 องค์ประกอบ: **ตัวป้อน (Input)**, **กระบวนการ (Process)**, **ผลผลิต (Output)** และ **ข้อมูลย้อนกลับ (Feedback)**
   - สามารถเลือกจาก Dropdown หรือคลิกที่ข้อความตัวเลือก (ก, ข, ค, ง) เพื่อเติมลงในช่องว่างอัตโนมัติ
   - ระบบแจ้งเตือนเมื่อใช้ตัวอักษรซ้ำในข้อเดียวกัน

3. **Export เป็นไฟล์ PDF อัตโนมัติ**
   - ดาวน์โหลดเป็นไฟล์ PDF ขนาด A4 ความละเอียดสูงด้วยเทคโนโลยี `html2canvas` + `jsPDF`
   - **ตั้งชื่อไฟล์อัตโนมัติ:** ในรูปแบบ `เลขที่_ชื่อ_นามสกุล.pdf` (เช่น `12_สมชาย_ใจดี.pdf`)
   - รองรับการ Export เป็นใบงานเปล่าเพื่อนำไปแจกนักเรียนเขียนด้วยมือ

4. **ระบบบันทึกฉบับร่างอัตโนมัติ (Auto-Save)**
   - บันทึกข้อมูลอัตโนมัติลงใน `localStorage` และ `IndexedDB` ทุกครั้งที่มีการพิมพ์หรือเลือกคำตอบ
   - ป้องกันข้อมูลสูญหายกรณีเผลอกดปิดแท็บหรือปิดเบราว์เซอร์
   - มีปุ่ม "บันทึกฉบับร่าง" พร้อมแถบแสดงเวลาที่บันทึกข้อมูลล่าสุด

5. **โหมดสำหรับครูผู้สอน (Teacher Mode)**
   - ปุ่มตรวจคำตอบพร้อมคิดคะแนนเต็ม 10 คะแนน (แสดงเครื่องหมาย ✓ / ✗ รายช่อง)
   - ตัวเลือกเติมคำตอบเฉลยอัตโนมัติลงในใบงาน
   - ตัวเลือกแนบแผ่นเฉลยท้ายใบงาน (หน้า 4) เพื่อพิมพ์หรือ Export เป็นเฉลยสำหรับครู
